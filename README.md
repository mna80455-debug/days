## 📖 مقدمة عن المشروع (About The Project)

**"أيام"** هو تطبيق ويب تفاعلي وتأملي مصمم خصيصاً باللغة العربية، يهدف لمساعدة المستخدمين على عيش تفاصيل حياتهم بحضور ذهني كامل (Mindfulness). يبتعد التطبيق عن صخب تطبيقات المهام والإنتاجية التقليدية المسببة للتوتر، ويقدم بدلاً عنها واجهة زجاجية دافئة وتجربة بصرية تدعم الاسترخاء والامتنان اليومي وترتيب البيت الداخلي للأفكار والمشاعر.

## 🌟 الميزات الأساسية (Key Features)

### 1. الرحلة اليومية التفاعلية 🗺️
ترافق المستخدمة خلال ثلاث محطات رئيسية:
* **شروق جديد 🌅:** تحديد النوايا، تحديد هدف اليوم الأساسي، واختيار الحالة المزاجية من بين رموز تعبيرية دافئة.
* **الوقوف الواعي (جلسة التنفس والتأمل) 🧘‍♀️:** مؤقت تفاعلي للتنفس (شهيق، حبس، زفير) مع مولد ذبذبات صوتية مدمج (Web Audio Synth) لتشغيل أصوات خلفية هادئة (صامت، نبض عميق، مطر خفيف) دون تحميل ملفات خارجية.
* **مراجعة المساء والامتنان 🌙:** تدوين اللحظات السعيدة، والإجابة عن أسئلة تأملية ملهمة، وتقييم المهام المنجزة، والتخطيط الهادئ للغد.

### 2. اقتباسات مخصصة بالذكاء الاصطناعي 🤖
يقوم التطبيق بتوليد اقتباس أو تأمل تأملي مخصص يومياً مبني على **اسم المستخدم ومزاجه اليومي وهدفه الأساسي**، معتمداً على تكامل مرن وسريع جداً مع **Groq API (Llama 3.1 8B)** أو **Gemini API**، بالإضافة إلى نظام قوالب احتياطي ذكي في حال انقطاع المفتاح.

### 4. نظام الستريك المرن والتشجيعي 🔥
يقوم العداد بحساب أيام الالتزام المتتالية لتدوين الحضور الذهني مع إعطاء **فترة سماح (Grace Period)** ليوم كامل. في حال انكسار الستريك، يقدم التطبيق عبارات تشجيعية وداعمة بدلاً من العبارات العقابية أو المسببة للتوتر.

### 5. صندوق الذكريات الرقمي مع ضغط الصور السحابي 📸
* تدوين اللحظات السعيدة وتخزين الصور الشخصية.
* نظام ضغط ذكي تلقائي للصور (Canvas-based compression) للملفات التي تفوق 5 ميجابايت لتوفير مساحات التخزين.
* رفع فوري وسريع للصور مباشرة عبر خدمة **Cloudinary** السحابية.

### 6. لوحة التحليلات الذكية 📊
* **منحنى تقلب المشاعر (Mood Index Graph):** رسم انسيابي (SVG Spline) يعرض معدلات تقلب المزاج خلال 7 أو 30 يوماً الماضية، مع نصائح هادئة ودعم مخصص للمزاج السائد.
* **سحابة الامتنان (Gratitude Cloud):** لوحة تعرض الكلمات والأشياء الأكثر تكراراً في تدوينات المساء بطريقة تفاعلية مميزة.

### 7. العداد السنوي والتقويم 🗓️
* يعرض التقدم السنوي للمستخدمة ومقدار ما مر وما تبقى من العام الحالي بنسبة مئوية واضحة.
* عداد تنازلي ديناميكي للمناسبات السنوية والشخصية القادمة (أعياد ميلاد، امتحانات، ذكريات خاصة) لمعرفة الأيام المتبقية لها بسهولة.

## 🛠️ البنية البرمجية (Tech Stack)

* **الأساس:** HTML5, CSS3, React.js (Vite), JavaScript ES6.
* **التصميم والتأثيرات:** Vanilla CSS (Glassmorphism & Micro-animations)، متجاوب بالكامل مع الهواتف الذكية والأجهزة اللوحية.
* **إدارة البيانات والاستضافة:**
  - **Firebase Firestore:** لحفظ بيانات المستخدمين، تدوينات الصباح والمساء، المناسبات والذكريات.
  - **Cloudinary Sinking:** لرفع وتخزين صور الذكريات الشخصية.
  - **Vercel Hosting:** لاستضافة التطبيق ونشره بكفاءة عالية.
* **التشغيل التجريبي (Mock Mode):** يدعم التطبيق التخزين المحلي التام في المتصفح (LocalStorage) للعمل الفوري دون الحاجة لتهيئة قواعد بيانات خارجية.

## 🔒 حماية وأمان البيانات ومتغيرات البيئة (Security & Env)

للحفاظ على أمان البيانات والمفاتيح الحساسة، تم عزل جميع إعدادات الاتصال بالذكاء الاصطناعي وبوابات التخزين السحابي وقاعدة البيانات Firebase داخل متغيرات البيئة. يتم حظر رفع ملفات الإعدادات تلقائياً عبر تكوين صارم في `.gitignore`.

لإعداد البيئة وتطبيق الإعدادات الخاصة بكِ، انسخي قالب البيئة النموذجي:

```bash
cp .env.example .env
```

ثم افتحي ملف `.env` واملئي الحقول بالمفاتيح الخاصة بكِ:

```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_app_id

# Cloudinary Integration (اختياري لرفع صور الذكريات)
VITE_CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
VITE_CLOUDINARY_UPLOAD_PRESET=your_cloudinary_preset

# AI Integration (مفاتيح الذكاء الاصطناعي لتأمل الصباح والمساء)
VITE_GROQ_API_KEY=your_groq_api_key
VITE_GEMINI_API_KEY=your_gemini_api_key
```

## 🚀 كيفية تشغيل المشروع محلياً (How to Run Locally)

تأكدي من تثبيت [Node.js](https://nodejs.org) على جهازكِ، ثم اتبعي الخطوات التالية:

1. **تحميل المستودع:**
```bash
git clone https://github.com/mna80455-debug/days.git
cd days
```

2. **تثبيت الحزم والمكتبات:**
```bash
npm install
```

3. **تشغيل سيرفر التطوير المحلي:**
```bash
npm run dev
```

4. **بناء النسخة الإنتاجية:**
```bash
npm run build
```
